Payment links by price

Add one payment link for each price (US dollars). When a customer orders, the store shows a pay button that opens the link matching their total. A row with the price left empty is used for any price that has no link of its own.

To change the admin password, open Vercel → your project → Settings → Environment Variables → edit ADMIN_PASSWORD, then redeploy.

Change any wording on the store page. A box left as it is keeps the built-in Khmer text. Press ↺ to go back to the built-in text. Keep words in {curly brackets}, such as {n} or {store}, because the store fills them in. Press Save when done.
