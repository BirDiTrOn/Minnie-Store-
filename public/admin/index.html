Payment link for each price

Every price from your games is listed below. Paste that price's payment link next to it (a link made for exactly that amount). When a customer presses pay, the store opens the link for their total in the same window.

Telegram order alerts

The store sends a message to your Telegram chat when someone opens the payment pop-up and when they press "I have paid". Set it up in Vercel (see README), then press the button to check.

Orders show ⏳ PENDING first. When a customer presses "I have paid", the message gets ✅ Payment received and ❌ Not received buttons. Tap one in Telegram and the message changes to PAID: COMPLETE or NOT RECEIVED. Press "Turn on" once (and again if you change your domain).

To change the admin password, open Vercel → your project → Settings → Environment Variables → edit ADMIN_PASSWORD, then redeploy.
